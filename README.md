🐾 Blog da Mariana

Blog de Medicina Veterinária desenvolvido para publicação e organização de conteúdos informativos de forma simples, responsiva e acessível.

O projeto também foi utilizado para colocar em prática conhecimentos de desenvolvimento web, Git, GitHub, deploy e testes básicos de segurança.

🔐 Segurança

Antes do deploy foram realizados testes básicos de segurança e comportamento utilizando o DevTools do navegador.

Foram verificados pontos como:

* entradas inesperadas;
* entradas com grande quantidade de caracteres;
* comportamento dos elementos da página;
* possíveis erros no Console;
* manipulação de parâmetros;
* exposição de informações pelo front-end;
* funcionamento do site após os testes.

Nenhuma senha, chave de API ou outra informação sensível deve ser armazenada diretamente no código front-end.

🎯 Objetivo do projeto

O objetivo é criar um espaço dedicado à publicação de conteúdos relacionados à Medicina Veterinária, enquanto são aplicados conhecimentos adquiridos durante a formação em Análise e Desenvolvimento de Sistemas (ADS).

O desenvolvimento envolveu:

* Estruturação de páginas com HTML
* Estilização com CSS
* Responsividade
* JavaScript
* Bootstrap
* Controle de versão com Git
* Versionamento no GitHub
* Testes utilizando DevTools
* Deploy utilizando GitHub Pages

📦 Como executar

Clone o repositório:

git clone https://github.com/RomarioFilipeS/blog-da-mariana.git

Acesse a pasta:

cd blog-da-mariana

Abra o index.html no navegador ou utilize o Live Server no VS Code.
